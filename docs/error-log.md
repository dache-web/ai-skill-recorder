# エラーログ

## 記録ルール

- 対象はAIスキルレコーダー第1工程です。
- 発生日時はJSTのISO 8601形式で記録します。
- 同じエラーへの同じ対応は2回までです。2回で解決しない場合は、別の手法を検討します。
- 原因が確定していない場合は「推定」または「未特定」と明記します。
- パスワード、APIキー、個人情報、会社情報、録画内容、完全なローカルパス、端末名、社内URLは記録しません。
- 秘密になり得る値は `[REDACTED]`、パスは `<local-path>`、機器名は `<device>` と記録します。

## 記録テンプレート

### ERR-YYYYMMDD-NNN: 短い題名

- 発生日時:
- 発生した操作:
- 環境: Windows / ChromeまたはEdge（端末を特定する情報は書かない）
- 分類:
- 同一エラー署名:
- 試行回数: 1 / 2
- エラー内容（秘密情報を除去済み）:
- 原因: 確定 / 推定 / 未特定
- 対応方法:
- 結果: 解決 / 未解決 / 再現せず
- 再発: あり / なし / 未確認
- 次に試す別手法: 2回目で未解決の場合は必須
