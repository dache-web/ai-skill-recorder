# 画像注釈機能の将来要件

この機能はSTEP2-1では実装しない。AI解析後に使用画像が決まった後の、手順書編集・画像仕上げ工程で実装する。

## 基本方針

- Excelの「挿入 → 図形」に近い選択式とし、自由描画ツールにはしない。
- 元PNG、注釈データ、完成画像を分離し、元PNGを上書きしない。
- 音声なしでも、説明文・画像・図形・動画区間だけで手順を理解できるようにする。

## 図形と操作

- カテゴリ: 矢印、囲み、強調、線、吹き出し、文字、手順番号
- 基本操作: 追加、移動、拡大、縮小、削除
- 矢印・線: 始点と終点を変更可能にする。
- 文字: 内容を変更可能にする。
- 色: 赤、黄色、青、緑、黒、白などから選択する。
- 線幅: 細い、普通、太いから選択する。
- 文字サイズ: 小、中、大、特大から選択する。
- 手順番号は固定数ではなく、必要数を生成できる構造にする。

## データ方針

- 位置と大きさは0～1の正規化座標で保持する。
- `source`は`user`または`ai`とする。
- `status`は`proposed`、`accepted`、`rejected`を想定する。
- AI提案は`proposed`として保存し、利用者の採用前に正式反映しない。
- 元PNGへ直接描画せず、採用済み注釈と合成した完成画像を別ファイルとして生成する。

## 音声なし運用

- 説明情報は音声、後からの文字入力、AI推測のいずれか、または組み合わせを利用する。
- AI推測は利用者の確認前に確定しない。
- 完成マニュアルは音声再生を必須にせず、手順タイトル、説明文、画像、図形、手順番号、必要な動画区間だけでも利用可能にする。
